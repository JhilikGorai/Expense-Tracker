# 💰 Expense Tracker

A simple and responsive Expense Tracker built using **HTML, CSS, and JavaScript**.

This project helps users keep track of their income and expenses in one place. You can add transactions, view your transaction history, and filter transactions by income or expense.

## 🚀 Live Demo

🔗 [View Live Demo](https://jhilikgorai.github.io/Expense-Tracker/)

## ✨ Features

- 💰 Track total balance
- 📈 Add income transactions
- 📉 Add expense transactions
- 📝 Add transaction descriptions
- 💵 Enter transaction amounts
- 📋 View transaction history
- 🔍 Filter transactions by:
  - All
  - Income
  - Expense
- 🗑️ Delete transactions
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
